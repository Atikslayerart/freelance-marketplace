# FreelanceHub Client

React frontend for the FreelanceHub freelance marketplace.

## Tech Stack

- React
- React Router
- Tailwind CSS
- Axios
- Vite

## Setup

```bash
npm install
npm run dev
```

The frontend runs at:

```text
http://localhost:5173
```

Make sure the backend is running at:

```text
http://localhost:5000
```
